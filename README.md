# 🌍 AI TravelMate

An AI-powered travel assistant that plans personalized trips, recommends destinations, and chats with users using NLP.

---

## 🚀 Features
- 🧠 AI chatbot (NLP based)
- 🗺️ Location-based travel recommendations
- ☁️ Real-time weather integration
- 💬 Voice/text assistance (Flask backend)

---

## 🧩 Tech Stack
**Frontend:** HTML, CSS, JavaScript  
**Backend:** Python (Flask)  
**AI Modules:** NLP + Recommendation system  
**APIs:** OpenWeatherMap, Google Maps
